## 开始试用

- 打开内置示例，调整构图和外观，切换明暗主题与俯斜视角。
- 导出 SVG／PNG 保存画面，导出 JSON 留待继续编辑。作品保留在当前浏览器，重要作品请另存 JSON。
- 想从魔法描述生成，填写自己的 DeepSeek API Key。描述直接发送给 DeepSeek，费用由你的模型账户承担；Key 仅留在当前页面内存，刷新或关闭后清除。

看示例、手工编辑和导出无需 Key。下载仓库 ZIP 并解压后，也可打开 `try/index.html` 离线使用；调用模型时需要联网。生成结果可以继续调整，模型与画面效果仍在打磨中。
