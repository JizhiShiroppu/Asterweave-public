# Asterweave · 编织星辰

**把魔法阵当成程序来设计，做一款美观、实用的「魔法世界 PCB 画板工具」。**

我想做的，是让法阵里的符文、子阵和连接各有职责：为什么放在这里、先做什么、哪些同时进行、何时停止，都能说得清楚；同一份描述，也能重新生成同一个结果。

目前已有可以离线运行的实验工具。**文字程序基础阶段已完成；图样与视觉规则仍在研究。** 这个公开库展示实际成果、说明能力边界，也欢迎感兴趣的人一起来做。开发源码在私有库维护，这里开放讨论、设计提案和展示资料的修改。

![三域引光：基础几何与分配通路候选](assets/three-light.svg)

*「三域引光」来自已完成的图样研究工具，以基础几何和明确通路试作一处来源、三路去向。它是可编辑的关系候选，尚未接入文字程序，也不代表魔法执行机制已经成立。*

## 它想解决什么

写小说、做世界观或设计游戏时，我希望魔法阵不只是漂亮的背景图，还能成为一种可以研究和设计的工具。

例如，一条火焰锁链可以拆成：

```text
凝聚火焰 → 塑成锁链 → （束缚目标 + 灼烧目标）
```

`→` 表示先后，`+` 表示并行。这是旧画板已有的简写。自由词段描述要做的事，明确的工作关系组织结构；新文字试验台进一步保存对象、参数、子阵接口与来源。

整阵对应程序，子阵可以承担模块或函数的职责。目标是让几何、符文与分布共同表达关系，经过少量调整得到完整、美观、可以继续修改的平面法阵。当前还没有打通任意文字程序到完整成阵的自动生成流程。

## 已经做到哪一步

| 已完成的能力 | 当前边界 |
| --- | --- |
| **文字程序**：对象与参数、可复用子阵、返回值及来源检查；顺序、并行与显式分支产出 | 操作由明确接口描述，不根据操作名称自动证明魔法机制 |
| **控制与预演**：条件选择、有限重复、先／后判断循环、组合条件、持续活动的启动／保持／解除 | 外部条件或检测结果须明确提供；缺少结果会等待，不模拟效果、耗时或能量 |
| **图样研究**：八种基础几何、八种衍生图样、八个构图起点；独立关系通路与两形范围 | 独立于文字层；条件、互锁、持续作用与解除的成阵规则仍待研究 |
| **图样编辑**：换形、增删、叠入一层基础几何，调整位置／角度／尺寸、锁定、撤销与重新安排 | 研究界面尚不是整合全部流程的正式创作工作台 |
| **旧画板**：铭文分工与续圈、局部扩容、控制预演、条幅连接、缩放聚焦与局部改写 | 保留作实验与历史对照；其控制画法不直接作为新系统的标准阵形 |
| **保存与复现**：明暗主题，相关入口的 SVG／JSON 导出与载入，原文、关系、版本及微调分别保存 | 各类作品按对应格式与入口重建，尚无统一作品格式或通用迁移器 |

## 想找什么样的协作者

不需要先懂完整代码，也不需要先定义一整个魔法体系。能带来一个具体例子、一张改图或一段实现，就可以开始。

| 方向 | 可以从这样一件小事开始 |
| --- | --- |
| 视觉、字体与交互 | 用三角、方形、六边形、菱形或星形改一张组合图，说明主次与留白 |
| 规则与世界观 | 给一个图样提出明确的工作关系，列出对象、来源、接口及不能表达的部分 |
| 几何布局与布线 | 提供一个最小拥挤或跨线案例，区分相交、共享与接通 |
| 前端与工具开发 | 围绕现有保存、微调、解释与预演提出一个具体改进，先讨论范围 |
| 测试与文档 | 找出展示说明和实际能力不一致的地方，提供复现步骤或更易懂的读图说明 |

## 几条设计原则

- 工作关系明确保存；字符编码只制作字形，不用散列值猜测词义。
- 自由词段是开放词表；七星投影只是当前主要的符文制作方案。
- 原文、取义、关系、来源与人工微调分别保存，有损字形不承担原文存档职责。
- 同一份输入、参数和版本应能复现；确定性本身不等于规则合理。
- 复杂度按轮廓、分段、交叉、开口和分区比较，不等于强弱或能耗。
- 先做好完整平面法阵，再推进动效和真正立体构造。

## 关于这个公开库

这里是展示与协作入口，暂不提供完整工具下载或在线试玩。原型以本地 HTML 运行，不依赖模型服务；自然语言入口属于后续阶段。

展示图由本项目生成，已去除完整作品元数据，未包含外部参考图、小说资料或私有开发历史。项目尚未选定通用开源许可证，代码与素材的使用授权请与维护者确认。

**English:** Asterweave is an offline prototype of a visual programming tool for magic circles, inspired by PCB design. The text foundation supports reusable subcircles, explicit control relationships and symbolic previews. Editable geometry and relationship studies remain separate from the text layer; general automatic composition is unfinished. This repository shares completed outputs and welcomes collaborators. Development source is private; please start with an issue.
