# 项目原则与路线

目标是从自由描述出发，经过少量主动调整，生成美观、有逻辑、可以保存并继续修改的平面法阵。使用体验像魔法世界里的 PCB 画板，内部组织思路像可视化编程器。

## 六个职责，逐步连接

| 职责 | 要解决的事 |
| --- | --- |
| 输入与意图整理 | 把描述整理为明确程序；近期用伪程序，后期加入自然语言入口 |
| 法阵程序核心 | 保存操作、对象、参数、关系与子阵调用，检查、释义和预演 |
| 符文制作 | 保存字形、方法及来源；七星投影是当前方案之一 |
| 自动构图与排版 | 安排子阵、路径、铭文与留白，不能为排版偷偷改变工作关系 |
| 绘制与编辑 | 查看解释，调整位置、角度、尺寸，锁定与撤销 |
| 作品资料与复现 | 分别保存原文、关系、版本、自动布局与人工调整 |

这是产品分工，不表示六部分已整合完成。文字试验台、图样研究和旧画板仍有各自的格式与边界。

## 五个阶段

| 阶段 | 本次展示对应的状态 |
| --- | --- |
| 1. 文字程序基础 | **已完成**：代表性程序可独立表达、检查、释义、复用及符号预演 |
| 2. 程序到视觉的规则 | **研究中**：已有基础几何组合、图样及关系候选，尚未接通文字程序 |
| 3. 自动构图质量 | **未完成**：任意支持程序的布局、布线和铭文排版仍需推进 |
| 4. 完整创作工作台 | **未完成**：研究界面尚未整合为正式创作流程 |
| 5. 自然语言入口与发行收敛 | **未完成**：尚未接入语言模型或提供完整工具发行 |

本次只反映工程 0.26.0 已完成快照，不收录同步开发任务，也不承诺排期。

## 现在适合参与的研究

先从美观、可用的图样出发，再探索它能承载的明确关系，最后针对真实缺口补充规则。三角、方形、六边形、菱形、五角星、六芒星与圆都值得研究，不靠持续增加复杂纹样取得丰富度。

可以改进一张基础几何组合，提出一组有明确对象、来源和接口的关系，或提供一个最小布线反例。复杂度按轮廓、分段、交叉、开口与可辨分区比较，不把分区数当作操作数，不把越复杂当作越强。

程序中的判定、选择、循环和维持已经可以表达；它们怎样成为好看、可读、有依据的实际阵形仍待研究。流程图与电子逻辑门只辅助解释，给它们添加符文装饰不能代替成阵设计。

## 后续与开放问题

继续完善视觉规则和自动构图，随后整合完整创作工作台与自然语言入口。动效和真正立体构造排在完整平面法阵之后。

自然语言模型可作为可选前端，将意图整理为明确程序，再由核心校验。复现依据是采纳并保存的程序、参数和版本，不是重新请求模型；离线核心不依赖模型可用性。

基础操作的能力边界、几何怎样承担工作约束，以及制作成本和临场灵活性的取舍仍需实例研究。意志负担与魔能消耗分别讨论，目前没有量化公式。软件试验与小说正式定案分别维护。
