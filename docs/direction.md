# 项目原则与下一步

目标是让法阵既好看，也能解释、设计和稳定复现。使用体验像魔法世界里的 PCB 画板，内部组织思路像可视化编程器。

## 分成四件事

1. **表达工作关系**：保存原文、取义、操作与作用范围，明确先后、并行、条件和循环。
2. **安排几何**：依据关系组织父子层级、通路和连接，逐步处理避障与交叉。
3. **制作符文**：把词段变成字形，保存方法、版本与来源。当前使用七星投影，未来可换方案。
4. **呈现与编辑**：形成有主次、可读的成品，让人查看解释、修改并导出。

这些职责应逐步解耦。字形不同可以影响尺寸和排版，但不能用字形的散列值决定词义与逻辑。

## 近期最需要推进的事情

| 方向 | 一个可讨论的完成标准 |
| --- | --- |
| 持续维持的解除与退出 | 解除来源明确，解除前等待、解除后退出，并能和嵌套及并行组合 |
| 条件循环 | 停止条件、重入与退出规则明确，缺少判断时不会擅自继续 |
| 混合层级与布线 | 用可复现案例检查避障，区分交叉、共享和接通，排不开时明确提示 |
| 平面美感与可读性 | 在真实关系结构上改善主次、留白、密度与读图，不以装饰遮盖问题 |

以上是协作方向，尚未给出排期或认领承诺。可以先提出其中一个小范围问题。

## 稍后再做

通用载入、局部编辑、模块替换、可复用子阵的参数与输入／输出，以及第二种符文制作方式。完整平面流程成熟后，再探索解释工作过程的动效和真正立体构造。

自然语言模型可以在后期作为可选前端，把意图整理成明确程序，再由核心校验与生成。当前没有接入模型；离线核心不应依赖模型可用性。复现依据是采纳并保存的程序，不是重新请求模型。

## 仍然开放的问题

几何如何承担更多工作约束、符文制作与世界内规则如何衔接、复杂结构如何平衡制作成本和临场灵活性，都需要实例研究。意志负担与魔能消耗分别讨论，目前没有量化公式。

软件试验与小说正式定案分别维护，不要求协作者接受某一套已经封闭的世界观。
