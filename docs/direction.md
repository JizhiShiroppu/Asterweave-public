# 当前近况

Asterweave 正在制作一款法阵创作工具，希望让魔法描述变成可以观看、调整和保存的作品。

现在可以[在浏览器里试用星辰工作室](https://jizhishiroppu.github.io/Asterweave-public/try/)：打开示例、生成法阵、调整构图与外观，并导出作品。先从[潮汐归城等五个样例](gallery.md)看看效果，也可以从较小的[苔灯](program-example.md)开始。

复杂画面还有拥挤和遮挡，模型对描述的理解也可能需要调整。接下来继续打磨画面与操作体验，以实际试用中遇到的问题为依据。

想保存后继续修改，请在工作室导出 JSON；图库里的 SVG 是展示图片。
