# 苔灯

让苔藓发出脚边的微光，沿来路导引，维持安静，最后熄灭。这是一件较小的法阵样例。

![苔灯 · 斜视](../assets/moss-lamp-dark-oblique.svg)

斜视看层次，俯视看整体。打开完整图片，可以放大看看环带与纹样。

![苔灯 · 俯视](../assets/moss-lamp-dark-flat.svg)

想自己动手，可以[打开星辰工作室](https://jizhishiroppu.github.io/Asterweave-public/try/)，从内置示例开始调整。保存 JSON 后可继续编辑；本页的 SVG 仅供看图。
