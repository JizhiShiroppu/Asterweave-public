# 文字程序实例：先制作，再复用

文字基础已能保存对象、参数、子阵输入／输出和来源，独立完成检查与符号预演。下面节选自已经实际运行的「双侧协同守护」，不是自然语言自动理解演示。

```text
子阵 制作入口屏障（颜色：文本，已经对准：外部条件）返回 对象：
    并行：
        分支 凝聚核心 产出 核心：
            光核 = 执行「凝聚光核」（颜色：$颜色）
            直到 $已经对准：
                执行「调整光束」（目标：$光核，方向：「对准入口界标」）
            交出 $光核
        分支 构筑外框 产出 框架：
            外框 = 执行「构筑框架」（形态：「六边形」）
            交出 $外框
    成品 = 执行「组装屏障」（核心：$核心，框架：$框架）
    返回 $成品
```

两支分别交出核心与框架，全部完成后才能组装。这里的「直到」先执行内部操作再检查条件；缺少外部结果时等待，不猜测是否已经对准。同一个子阵可以被多次调用，各次调用的参数、对象和返回来源分别记录。

完整实例还包含光色选择、两侧并行守护、组合条件巡查、屏障的启动／保持／解除，以及最后的汇合。四个子阵、八次调用，在给定的完整外部输入下产生 **88条真实预演记录**，末尾为：

```text
86. 并行1的“东侧守护”分支完成
87. 并行1全部分支完成，汇合并继续
88. 执行「记录」（内容="两侧守护均已完整结束"）
预演状态：完成。
```

以上末尾记录省略了原报告逐条附带的来源行号和调用路径。来源为工程 0.26.0 快照保留的 `language-coordinated-ward.txt`，文字算法为 `asterweave-text-v2`。

界面可以编辑原文、接口和本次输入，查看释义、分支进度、保持中的活动以及对象来源。局部程序图解可辅助理解关系、选择单元并微调，但不作为实际成阵样例。

预演只展示明确规则下的符号过程。「凝聚光核」「组装屏障」等操作仍是接口，不执行真实魔法或效果模拟；记录次序不表示并行操作的实际耗时、速度。该程序尚不能自动生成对应的完整法阵。
